# v1.0.0 Release Notes

### Features

- LCC2 data format support (beta)
- VR stereo rendering (Instanced Stereo) support
- Rendering quality improvements

### Bug Fixes

- Fixed collision not taking effect or not updating correctly under multi-camera, multi-SceneCapture, VR, and split-screen scenarios
- Fixed color shift caused by Tonemap in SceneCapture / MRQ, etc.
- Fixed sort order between LCC and translucent rendering; LCC now has the lowest render priority so VFX always draw in front of it

### Compatibility

- Supported engine versions: UE 5.4 / 5.5 / 5.6 / 5.7
- UE 5.1 – 5.3 are no longer supported

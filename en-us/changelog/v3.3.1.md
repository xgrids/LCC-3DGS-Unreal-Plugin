# v3.3.1 Release Notes

### Features

**Rendering**
- Added GPU-driven indirect draw for improved rendering efficiency
- Added SingleLayerWater support option for water surface rendering (Project Settings > Plugins > LCC4Unreal > SingleLayerWater Support)
- Added ShowCollision and ShowFPS quick actions on the Actor panel
- Added reverse-play load animation

**Data Format**
- Added SPZ v2 format support (Marble exported Gaussian Splatting)
- Support for larger SOG / SPZ / PLY models

**GIS Integration**
- Replaced engine GeoReferencing with built-in PROJ library to reduce external module dependencies
- SOG / SPZ / PLY actors automatically rotate around the X-axis to match external Gaussian Splatting coordinate conventions

**Collision**
- Added navigation mesh (NavMesh) support for AI pathfinding
- Optimized collision debug visualization rendering performance

**Editor**
- Added focus root component for viewport camera focus (press F to frame)
- Multi-language localization (Chinese, German, French, Japanese, Korean)

### Improvements

- Optimized collision loading efficiency; default collision loading distance increased to 300 meters
- Optimized SPZ / SOG / PLY rendering performance, significantly improving frame rate during navigation

### Bug Fixes

- Fixed sphere clipping volume rotation not taking effect in shader
- Fixed editor hang when loading data sources asynchronously
- Fixed collision data memory leak caused by unbounded queue accumulation
- Fixed PROJ data files not being staged in packaged builds
- Fixed actor load state not persisting across sessions
- Fixed public key authentication not working with Unicode paths
- Fixed inaccurate node culling by using closest-point distance calculation
- Fixed GPU sort parameter conflicts by using a dedicated staging buffer
- Fixed performance drop caused by insufficient GPU memory
- Fixed load animation not taking effect at Runtime
- Fixed height-based coloring issue on SOG / SPZ / PLY actor point clouds

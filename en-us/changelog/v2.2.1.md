# v2.2.1 Release Notes

### Features

- Depth output support, enabling multi-LCC2 blended rendering and correct blending with other translucent objects
- Added DOF (Depth of Field) support
- Added OpenColorIO support
- Added TSR / TAA anti-aliasing support
- Added LCC2-SPZ format support

### Improvements

- Refactored compositing pipeline to reduce rendering overhead
- Reduced shader resource usage
- Optimized cache eviction strategy to prevent visual artifacts

### Bug Fixes

- Fixed rendering flickering in various scenarios
- Fixed crashes and stability issues when loading large scenes
- Fixed Linux compilation issues
- Fixed file loading failure with non-ASCII paths on Windows

# v3.0.0 Release Notes

### Features

**Data Format**
- Added PLY format support
- Added SOG single-file loading support
- Added SPZ format support, compatible with both v3 and v4

**Rendering**
- Added multiple normal simulation methods (ViewFacing / Hemispherical / Fixed)
- Added Mip Filter toggle for splat rasterization
- Added Post Process Volume support
- Added NVIDIA DLSS support
- Added Color Correction Region support
- Added ACES/OCIO color space conversion workflow support

**Pro Features**
- Added ProxyMesh feature
- Added ACES workflow support
- Added large-scale clipping volume support

### Bug Fixes

- Fixed stereo rendering (VR) black screen issue
- Fixed occlusion anomaly when 3DGS depth is in front of scene
- Fixed D3D12 RenderTarget texture compatibility issue
- Fixed shutdown hang during cache thread release
- Fixed LCC2 scaling error

### Improvements

- Improved Deferred Lit Mode rendering quality

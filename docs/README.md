# LCC Plugin for UE

Developer documentation for **LCC4Unreal**, a 3D Gaussian Splatting (3DGS) rendering plugin for Unreal Engine 5 built by XGRIDS. Load, render, relight and edit billion-point Gaussian Splat scenes in-engine.

**[Documentation for v3.3.1 →](./v3.3.1/)**

| | |
| --- | --- |
| Engine | UE 5.4 – 5.8 (v1.0.0 and above) · UE 5.1 – 5.7 (below v1.0.0) |
| Platform | Windows (Win64, cross-compiles to Linux x86) · native Linux x86 |
| Formats | LCC2, LCC, SOG, SPZ, PLY |
| Graphics API | DirectX 11, DirectX 12, Vulkan |

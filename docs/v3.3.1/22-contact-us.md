# Technical Support and Developer Community

For problems this documentation does not cover, or when custom support is needed, contact us through the channels below.

## Technical Support Email

<sdk@xgrids.com>

Suitable for the following cases:

- Using the plugin on a custom engine version, including vendor-customized branches, commercial engines derived from UE, and engines with locally modified source, see [Custom Engine Versions](./12-integration.md#custom-engine-versions)
- Problems while applying for a [Pro edition](./05-pro-features.md) license
- Submitting a bug report or a feature request

When reporting an issue, attach the plugin version, engine version, data format, and the related errors from the Output Log to help with diagnosis.

## Developer Platform

<https://developer.xgrids.com>

A comprehensive platform for developers, providing:

- Plugin installer downloads and version updates
- App Key application and management
- A developer forum for asking questions, reading other people's solutions, and taking part in technical discussions
- Documentation and sample resources

## GitHub

<https://github.com/xgrids/LCC-3DGS-Unreal-Plugin>

The public repository of the plugin. Bug reports and feature requests can be submitted in Issues, where known issues and discussions are also visible.

## Discord Community

[Join the Discord community](https://discord.gg/b99H8wjRaH)

Exchange experience with other developers and get the latest updates.

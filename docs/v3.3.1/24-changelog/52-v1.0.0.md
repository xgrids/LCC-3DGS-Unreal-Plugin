# v1.0.0

> Note: supports UE 5.4 / 5.5 / 5.6 / 5.7. UE 5.1 ~ 5.3 are no longer supported.

---

### New Features

- Added lcc2 format support (beta)
- Added VR stereo rendering (InstanceStereo) support
- Improved rendering quality

---

### Fixes

- Fixed collision not taking effect or not updating with multiple cameras, multiple SceneCaptures, VR, and split screen
- Fixed the color shift previously caused by Tonemap (SceneCapture / MRQ and similar)
- Fixed the sorting of blended rendering between lcc and translucent objects; lcc now has the lowest rendering priority, so effects always render in front of lcc

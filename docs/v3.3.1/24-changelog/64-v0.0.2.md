# v0.0.2

---

### New Features

- Added an adjustable LOD strategy, with customizable view distance and switching weight per LOD level
- Added a ring loading strategy that loads the surrounding data automatically based on the camera position for smoother roaming
- Added relative path loading for LCC, so LCC data placed in the project Content directory can be read without an absolute path and still works after packaging

---

### Improvements

- Greatly improved rendering speed

---

### Fixes

- Fixed several memory leaks
- Fixed incorrect LOD level calculation
- Fixed the incorrect spherical harmonics parameters that could lead to wrong color calculation

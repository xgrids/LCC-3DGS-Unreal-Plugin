# v0.0.1

---

### New Features

- Added LCC data loading, so lcc files in a given directory can be loaded and rendered in UE5
- Added basic editing in the editor, allowing overall translation, rotation, and scaling in the Editor
- Added redistribution support, so applications built on top of the plugin can be packaged and released
- Render sorting is fully GPU accelerated for smoother performance

---

### Fixes

- Fixed program stability and dx11 support

# v2.2.1

> Note: all new features, fixes, and improvements below apply to the LCC2 rendering pipeline only, not the legacy LCC pipeline.

---

### New Features

- Added depth output, blended rendering across multiple LCC2 Actors, and blended rendering with other translucent objects
- Added DOF (depth of field) support
- Added OpenColorIO support
- Added TSR/TAA anti-aliasing support
- Added support for the LCC2-SPZ format

---

### Improvements

- Reworked the compositing pipeline to reduce rendering overhead
- Trimmed shader resource usage
- Improved the cache eviction policy to prevent black holes in the image

---

### Fixes

- Fixed rendering flicker in several scenes
- Fixed crashes and stability issues when loading large scenes
- Fixed compilation on the Linux platform
- Fixed loading failures with Chinese paths on Windows

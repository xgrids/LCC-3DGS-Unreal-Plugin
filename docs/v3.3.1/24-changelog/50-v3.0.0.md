# v3.0.0

---

### New Features

**Data Formats**
- Added support for the PLY format
- Added support for loading a single SOG file
- Added support for the SPZ format, compatible with both v3 and v4

**Rendering**
- Added several normal simulation methods (ViewFacing / Hemispherical / Fixed)
- Added a Mip Filter toggle to control Mip filtering during splat rasterization
- Added post process volume support
- Added NVIDIA DLSS support
- Added color correction region support
- Added support for the ACES/OCIO color space conversion workflow

**Pro Features**
- Added ProxyMesh
- Added ACES workflow support
- Added support for very large numbers of clipping volumes

---

### Improvements

- Improved the rendering result of the deferred lit mode (Deferred Lit Mode)

---

### Fixes

- Fixed the black screen in stereo rendering (VR)
- Fixed abnormal occlusion when the 3DGS depth is in front of the scene
- Fixed RenderTarget texture compatibility under D3D12
- Fixed the shutdown hang when releasing the cache thread
- Fixed incorrect LCC2 scaling

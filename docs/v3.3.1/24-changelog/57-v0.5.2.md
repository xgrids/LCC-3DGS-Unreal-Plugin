# v0.5.2

---

### New Features

- Added support for box and sphere clipping volumes to clip the scene
- Added support for section planes to section the scene
- Added nDisplay support
- Added Aximmetry support (the LCCActor Replace Tonemap option must be off, and scene exposure is controlled with a post process volume)
- Added VR rendering support (the Instanced Stereo option must be off)

---

### Improvements

- Added node preloading for smoother scene runtime

---

### Fixes

- Fixed the rendering error caused by rotating the scene around the Z axis
- Fixed the environment node issue in multi-camera setups
- Fixed incorrect chunking in some scenes
- Fixed incorrect Node level calculation in some scenes

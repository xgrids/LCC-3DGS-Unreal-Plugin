# v0.8.0

---

### New Features

- Added CesiumForUnreal plugin support
- Added the multi-LCCActor auto sorting toggle `bEnableMultipleLCCActorAutoSort`, allowing the rendering order of multiple LCC Actors to be managed manually
- Added `SortFactor` to set the sorting frequency of an individual LCCActor
- Added full load rendering mode
- Added the `bEnableEditorCollision` toggle, off by default, controlling whether collision data is loaded in editor mode
- Added `bEnableSeamCutting` to resolve seams in chunked rendering; it must be toggled manually before LCC 4.0 and is enabled automatically in 5.0 and above
- Added a watermark
- Added a seamless air-ground roaming strategy
- Added LCC color adjustment
- Added a Refresh method to LCCClippingVolume and LCCSectionPlane

---

### Improvements

- LCC logic no longer runs while it is hidden
- Added a Node Cache to speed up traversal

---

### Fixes

- Fixed enabling and disabling collision dynamically
- Fixed several issues with building, cooking, and updating in the collision system
- Fixed the incorrect public_key.pem path
- Fixed several issues with C++ header includes
- Renamed the ReceiveShadow.uasset file
- Fixed seams in chunked rendering
- Fixed the oversized LCC Bound
- Fixed issues with LCCActor used as a ChildActor
- Fixed the crash when opening the same level repeatedly in quick succession
- Fixed the crash caused by rapid Refresh calls
- Fixed the null pointer caused by GeoRef

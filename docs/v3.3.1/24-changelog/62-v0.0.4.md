# v0.0.4

---

### New Features

- Added environment data support, so the environment data of 3D Gaussians can be loaded and rendered
- Added chunked rendering to improve rendering and roaming speed and stability in large scenes while greatly reducing memory usage
- Added near field quality control to adjust the sharpness level of the near field rendering around the camera
- Added support for loading the LCC 3.0 data format

---

### Fixes

- Fixed the crash triggered by dragging the parameter sliders
- Fixed multithreading stability issues

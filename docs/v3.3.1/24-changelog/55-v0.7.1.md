# v0.7.1

---

### New Features

- Added Linux platform support (cross compilation)
- Added support for legacy collision data (collision.bin)
- Added support for the 3DGS ply format
- Added support for the Disguise software
- Added the `r.xgrids.ForceUpdate` command to force a scene refresh
- Added the `SetPlayerLoadMode` and `SetPlayerRenderMode` methods so the load mode and render mode can be set per camera in multi-camera scenes
- Added node filtering to filter out nodes that do not meet the condition (splat count)

---

### Improvements

- Improved the collision data loading strategy

---

### Fixes

- Fixed the rendering error when an LCCActor is rotated around the X axis
- Fixed the rendering issue when the x, y, z position values of an LCCActor are very large
- Fixed changes to UseShcoef not being saved
- Fixed the wrong numeric type of LevelFactor
- Fixed the sorting issue with multiple LCC Actors
- Fixed the environment node rendering issue with LCC 4.0 data
- Fixed the holes at the edges while turning quickly

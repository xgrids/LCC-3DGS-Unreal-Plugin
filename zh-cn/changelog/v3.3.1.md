# v3.3.1 发布说明

### 新功能

**渲染**
- 新增 GPU 驱动间接绘制，提升渲染效率
- 新增 SingleLayerWater 水面渲染支持选项（Project Settings > Plugins > LCC4Unreal > SingleLayerWater Support）
- Actor 面板新增 ShowCollision 和 ShowFPS 快捷操作按钮
- 新增反向动画功能

**数据格式**
- 新增 SPZ v2 格式支持（Marble 导出高斯）
- 支持更大尺寸的 SOG/SPZ/PLY 模型

**GIS 集成**
- 使用内置 PROJ 库替代引擎 GeoReferencing，减少对外部模块依赖
- SOG/SPZ/PLY Actor 自动沿 X 轴旋转以匹配外部高斯泼溅的坐标轴定义

**碰撞**
- 新增导航网格（NavMesh）支持，用于 AI 寻路
- 优化碰撞调试可视化渲染性能

**编辑器**
- 新增焦点根组件，支持视口相机聚焦（按 F 键框选）
- 多语言本地化支持（中文、德语、法语、日语、韩语）

### 优化

- 优化碰撞加载效率，默认碰撞加载距离提升为 300 米
- 优化 SPZ/SOG/PLY 渲染性能，大幅提高漫游时帧率

### 修复

- 修复球体裁剪框旋转在着色器中不生效的问题
- 修复异步加载数据源时编辑器卡死
- 修复碰撞数据因无限队列累积导致的内存泄漏
- 修复打包构建中 PROJ 数据文件未被正确包含
- 修复 Actor 加载状态在会话间未持久化
- 修复 Unicode 路径下公钥认证不工作
- 修复节点剔除使用最近点距离计算不准确
- 修复 GPU 排序参数冲突，使用独立暂存缓冲
- 修复因显存不足导致的性能骤降
- 修复 Runtime 下加载动画不生效的问题
- 修复 SOG/SPZ/PLY Actor 点云高度着色问题

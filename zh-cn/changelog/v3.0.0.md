# v3.0.0 发布说明

### 新功能

**数据格式**
- 新增 PLY 格式支持
- 新增 SOG 单文件加载支持
- 新增 SPZ 格式支持，兼容 v3 和 v4 两个版本

**渲染**
- 新增多种法线模拟方法 (ViewFacing / Hemispherical / Fixed)
- 新增 Mip Filter 开关，可控制 Splat 光栅化时的 Mip 过滤
- 新增后期盒子支持
- 新增 NVIDIA DLSS 支持
- 新增色彩校正区域支持
- 新增 ACES/OCIO 色彩空间转换工作流支持

**Pro 功能**
- 新增 ProxyMesh 功能
- 新增 ACES 工作流支持
- 新增超大规模裁剪框支持

### 修复

- 修复立体渲染 (VR) 下黑屏问题
- 修复 3DGS 深度在场景前方时的遮挡异常
- 修复 D3D12 下 RenderTarget 纹理兼容性问题
- 修复缓存线程释放时的关闭卡死问题
- 修复 LCC2 缩放错误问题

### 优化

- 改善延迟光照模式 (Deferred Lit Mode) 渲染效果

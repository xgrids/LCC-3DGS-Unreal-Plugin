# v1.0.0 发布说明

### 新功能

- 支持 LCC2 数据格式（beta）
- 支持 VR 立体渲染（Instanced Stereo）
- 渲染质量提升

### 修复

- 修复多相机、多 SceneCapture、VR、分屏等情况下碰撞未生效或未正确更新的问题
- 修复此前由 Tonemap 导致的偏色问题（SceneCapture / MRQ 等）
- 修复 LCC 与半透明混合渲染的排序问题：LCC 渲染优先级现为最低，特效始终会渲染在 LCC 之前

### 适配说明

- 支持引擎版本：UE 5.4 / 5.5 / 5.6 / 5.7
- UE 5.1 – 5.3 不再适配
